# Conditional GAN investigation

**Two bounded development-only studies; no tested GAN configuration beat matched oversampling.**

- [Findings and the next hypothesis](../../docs/gan-findings.md): measured outcomes, generation-quality diagnostics, omitted-feature audit and exact limits on what is established.
- [Natural minority-fit pilot](conditional-v1/report.md): 15 DNN runs, three CTGAN fits, two output doses, all three paired seeds and exact evidence tables.
- [Family-balanced follow-up](conditional-balanced-v1/report.md): the same comparisons, with all copied GAN-fit rows traced to real core sources.
- [Descriptive feature audit](feature-audit.json): ten fields omitted by the current model, measured only on core real training; these are class statistics, not performance scores.
- [Reproduction](../../gan_research/README.md): pinned dependencies, fresh output directories, locked plans and independent verification.

The studies use the same three seeds; repeated controls are not additional independent replicates. Neither study reopens the original test set. The proposed expanded-feature comparison has not been run. Raw feature records, generated pools and model objects remain in local storage; public archives contain exact IDs, lineage and predictions.
